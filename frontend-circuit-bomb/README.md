# Circuit Bomb

The third UI concept for Vandal, as a static skeleton: the company as a programmable circuit board. Copper traces are the workflow, cyan pulses are legitimate payments, Vandal's pulse is red. Detonate plays the scene: injection, breach, diagnosis, a refuted T2 gate, a T2 + T1 gate that stops the pulse, six checks and a signature. Not wired to the API.

```bash
npm install
npm run dev -- -p 3013
```
